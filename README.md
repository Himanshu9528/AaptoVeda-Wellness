# AaptoVeda Wellness

Educational guide to classical Ayurvedic science, body constitution (Doshas), and botanical adaptogenic profiles.

## Getting Started

**Prerequisites:** Node.js (v18+)

1. Install dependencies:
   ```
   npm install
   ```
2. Run the app locally:
   ```
   npm run dev
   ```
3. Build for production:
   ```
   npm run build
   ```

## Tech Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS
- Lucide icons
- Motion (animations)
